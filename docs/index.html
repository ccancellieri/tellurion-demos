Tellurion is a geospatial serving engine for features, tiles, rasters, multidimensional arrays, STAC and 3D. This guide separates what is ready in the current source tree from optional build features, previews and future work.

The default build includes the embedded GeoPackage path for catalogs, features, tiles and supported writes. It is the shortest self-contained evaluation route.

Additional data drivers

PMTiles, FlatGeobuf, GeoParquet, COG, Zarr, Iceberg and DuckDB are compile-time features. Support is read-only or capability-specific; enabling a driver does not make it read-write.

Download state

The GitHub Releases page is the only place to look for an approved, checksummed and attested binary release. Until one appears there, build the current source. GitHub may offer automatic source archives; a source archive is not an installable Tellurion binary.

Station 05

What is not supported

Refusing unsupported behavior is safer than returning an answer that looks plausible.

  • No universal read/write promise. Driver capabilities differ; several optional formats are explicitly read-only.
  • No automatic production readiness. A successful demo or local run does not replace security, capacity and operational review.
  • No benchmark claim from hosted demos. Shared infrastructure and cold starts make those timings unsuitable for comparison.
  • No DGGS or geometry/3D statistics API today. Current use cases deliberately exclude them.
  • No implied conformance. Consult each deployment’s /conformance response and the documented deviations.
