before you deploy.

Tellurion is a geospatial serving engine for features, tiles, rasters, multidimensional arrays, STAC and 3D. This guide separates the current public evidence from optional capabilities, previews and future work.

Station 05

What is not supported

Refusing unsupported behavior is safer than returning an answer that looks plausible.

  • No universal read/write promise. Driver capabilities differ; several optional formats are explicitly read-only.
  • No automatic production readiness. A successful demo or local run does not replace security, capacity and operational review.
  • No benchmark claim from hosted demos. Shared infrastructure and cold starts make those timings unsuitable for comparison.
  • No DGGS or geometry/3D statistics API today. Current use cases deliberately exclude them.
  • No implied conformance. Consult each deployment’s /conformance response and the documented deviations.
